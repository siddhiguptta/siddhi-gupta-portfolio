## Overview
This repository contains the source code and files for my Web Development Midterm Assignment. The project involves building and styling a personal resume and portfolio website using HTML5 and CSS3, enhanced with modern layout techniques (CSS Grid, Flexbox, sticky navigation bar) and hosted publicly via GitHub Pages.

## Features & Improvements
- Semantic HTML5 & Custom CSS3: Organized structure with dedicated styling for education, professional experience, campus leadership, achievements, and key skills.
- Sticky Flexbox Navigation Bar: Responsive top bar with smooth scrolling anchored to different sections.
- CSS Grid Card Layouts: Clean, modern card components with interactive hover effects and professional typography.
- Fully Responsive Design: Media queries ensure seamless viewing across mobile devices, tablets, and desktop screens.
